# Символьная RNN на PyTorch

Подготовка символьных последовательностей, собственная рекуррентная сеть, обучение и генерация текста.

| Файл | Назначение |
| --- | --- |
| [character_rnn.ipynb](character_rnn.ipynb) | Ноутбук с постановкой, реализацией и анализом |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
