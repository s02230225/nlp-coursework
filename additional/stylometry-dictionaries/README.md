# Стиль по словарям

Оценка принадлежности текста стилю по словарям частот и характерным словам.

| Файл | Назначение |
| --- | --- |
| [favoriteWords.py](favoriteWords.py) | Программа или модуль практикума |
| [main.py](main.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
