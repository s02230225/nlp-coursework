# Части речи и лексическая статистика

Разбор частей речи, стоп-слова, частоты и характеристики русского текста.

| Файл | Назначение |
| --- | --- |
| [text_analysis.py](text_analysis.py) | Программа или модуль практикума |
| [pos_statistics.py](pos_statistics.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
