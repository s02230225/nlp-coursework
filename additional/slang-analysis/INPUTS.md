# Входные данные и ресурсы

## slang_analyzer.py

Имена файлов и путей, используемые программой:

- `_report.txt`
- `_slang_by_content_pos.png`
- `_unknowns.csv`
- `data/slang_lemmas_copy.csv`

Корпуса, обученные веса и большие датасеты подготавливаются отдельно. Короткие словари, присутствующие в этой папке, включены рядом с программой. Ноутбуки по анализу поисковых моделей содержат свой небольшой текстовый корпус.

В data/slang_lemmas_copy.csv включён небольшой демонстрационный словарь из четырёх лемм. Полный исходный словарь не найден в архивной копии; расширение CSV не требует изменений программы. Для примера предусмотрен data/example.txt.
