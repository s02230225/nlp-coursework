# Словарные маркеры речи

Лемматизация, словарные категории сленга и англицизмов, распределение по частям речи и оценка с учётом жанра.

| Файл | Назначение |
| --- | --- |
| [slang_analyzer.py](slang_analyzer.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
