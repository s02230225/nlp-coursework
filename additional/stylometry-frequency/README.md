# Частотные признаки и стиль

Характерные слова автора, частоты корпуса и оценка стиля на основе текстовых признаков.

| Файл | Назначение |
| --- | --- |
| [determine_style.py](determine_style.py) | Программа или модуль практикума |
| [fav_words.py](fav_words.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Для обращений к частотному API задаётся `RUSCORPORA_API_TOKEN`. Сам токен в исходниках не хранится.
