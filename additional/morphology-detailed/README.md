# Морфологический анализ текста

Разбор существительных, прилагательных, глаголов и статистика словоформ и лемм.

| Файл | Назначение |
| --- | --- |
| [main.py](main.py) | Программа или модуль практикума |
| [morph.py](morph.py) | Программа или модуль практикума |
| [text_job.py](text_job.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
