# Профили авторов

Частотные профили, характерные слова, косинусное сходство и определение автора по тексту.

| Файл | Назначение |
| --- | --- |
| [analyze_author.py](analyze_author.py) | Программа или модуль практикума |
| [config.py](config.py) | Программа или модуль практикума |
| [identify_author.py](identify_author.py) | Программа или модуль практикума |
| [main.py](main.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
