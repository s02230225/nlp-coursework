Интерактивный анализ русскоязычного текста, лемматизация, словоформы и грамматические характеристики.

| Файл | Назначение |
| --- | --- |
| [main1.py](main1.py) | Программа или модуль практикума |
| [MyProg1.py](MyProg1.py) | Программа или модуль практикума |
| [TextInfo1.py](TextInfo1.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
