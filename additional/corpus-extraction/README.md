# Подготовка корпуса

Разбиение CSV с колонками class/text на текстовые корпуса по категориям.

| Файл | Назначение |
| --- | --- |
| [extract_categories.py](extract_categories.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
