# Лексическое разнообразие и сравнение текстов

Лексические метрики, распределение частей речи, сравнение текстов, отчёты и графики.

| Файл | Назначение |
| --- | --- |
| [comparator.py](comparator.py) | Программа или модуль практикума |
| [lexicon_core.py](lexicon_core.py) | Программа или модуль практикума |
| [main.py](main.py) | Программа или модуль практикума |
| [metrics.py](metrics.py) | Программа или модуль практикума |
| [reporter.py](reporter.py) | Программа или модуль практикума |
| [visualizer.py](visualizer.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
