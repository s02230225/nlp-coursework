# Распознавание букв

Подготовка изображений, обучение Keras-модели и распознавание символов.

| Файл | Назначение |
| --- | --- |
| [data_preparation.ipynb](data_preparation.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [letter_recognition.ipynb](letter_recognition.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [model_creation.ipynb](model_creation.ipynb) | Ноутбук с постановкой, реализацией и анализом |
| [letter_training.py](letter_training.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Ноутбуки открываются в Jupyter; ячейки выполняются последовательно. Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
