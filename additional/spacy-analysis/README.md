# Лексический анализ со spaCy

Статистика текста и частей речи, частотные таблицы и визуализация.

| Файл | Назначение |
| --- | --- |
| [analyser.py](analyser.py) | Программа или модуль практикума |
| [main.py](main.py) | Программа или модуль практикума |
| [simple_tests.py](simple_tests.py) | Программа или модуль практикума |
| [visualise.py](visualise.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).
