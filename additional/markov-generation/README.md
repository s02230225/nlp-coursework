# Генерация текста цепью Маркова

Построение переходов по корпусу, генерация предложений и интерфейс Tkinter.

| Файл | Назначение |
| --- | --- |
| [main.py](main.py) | Программа или модуль практикума |
| [MarkovChain.py](MarkovChain.py) | Программа или модуль практикума |

Зависимости устанавливаются для выбранной работы отдельно:

```bash
python3 -m pip install -r requirements.txt
```

Скрипты запускаются из этой папки. Необходимые входные файлы и ресурсы перечислены в [INPUTS.md](INPUTS.md).

Интерфейс использует Tkinter; в Linux он устанавливается отдельно средствами системы.
