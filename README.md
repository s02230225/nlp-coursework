# Практикум по анализу неструктурированных данных

**Python · NLP · модели текстов**

Учебные работы по регулярным выражениям, сегментации, обработке русскоязычных текстов и нейросетевым моделям. Папки сохраняют тематические и календарные названия практикума.

Начальные примеры:

```bash
python3 "дз1/task1.py"
```

Ноутбуки открываются в Jupyter. Перед запуском конкретной работы следует подготовить её данные и зависимости, указанные в первых ячейках или импортах: nltk, razdel, pymorphy, NumPy, PyTorch либо TensorFlow в зависимости от темы. Разные работы не требуют одновременной установки всех библиотек.

Корпуса и обученные веса в подборку не включены. Отдельный анализатор тональности находится в [russian-text-analysis](https://github.com/s02230225/russian-text-analysis).
